# DESIGN.md v1.1

## Direction
Human-made / restrained / portfolio-first / editorial without mannerism.

## Core rules
- Work comes before decorative typography.
- No giant slogan occupying most of the viewport.
- No serif-italic as a default visual trick.
- No numbered section system unless it serves navigation.
- No black final section with oversized CTA purely for impact.
- No repeated card grid.
- No beige + orange + black "design portfolio" cliché.
- Use neutral light background, black text, and let project visuals provide color.
- Japanese copy is written independently, never literal translation from English.
- Japanese name: 堀内 美枝.
- English name: YOSHIE HORIUCHI.
- Bilingual toggle: JP / EN.
- Main type: Noto Sans JP / Manrope.
- Layout should vary by project: full-width image, split layout, vertical reel, product strip.
- UI should stay quiet.
